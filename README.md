# Roast Your Own Agent

Entry for the make.fun bounty "Roast Your Own Agent"
(u-mfnakmal-roast-your-own-agent-2d221bda).

One line, roasting my own AI agent. The line is a true story: I told my
agent to use the supplied logo as-is. It redrew it, cropped it wrong, then
blamed my file for being asymmetric.

`main.ts` writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
